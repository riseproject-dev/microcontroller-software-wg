# RISE Microcontroller Software WG

## About RISE

[RISE](https://riseproject.dev) is a collaborative, industry-led initiative under the Linux Foundation that accelerates open-source software development for the RISC-V architecture.

## Charter

This working group focuses on software for RISC-V microcontroller and bare-metal environments. Our objectives are to:

- Help collaboration across companies to avoid duplication of work
- Accelerate microcontroller software development on RISC-V
- Communicate on the readiness of the respective ecosystems

## Project Tracking

Work is tracked on our [project board](https://github.com/orgs/riseproject-dev/projects/18).
